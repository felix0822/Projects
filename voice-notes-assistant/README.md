# Голосовой ассистент: тройной тап → запись → саммари в Заметках

Команда (Shortcut) для iPhone. Тройной тап по задней крышке запускает запись. После остановки
запись расшифровывается на телефоне, текст уходит в Claude API, а результат раскладывается так:

- **Заметки** — заметка с отметкой времени: кратко, ключевые моменты, решения, задачи, транскрипт;
- **Напоминания** — всё, что было сказано «напомни», «надо сделать к пятнице» и т.п.;
- **Часы** — будильники, если в записи прозвучало «поставь будильник на 7:30».

```
[тройной тап] → Записать аудио → [стоп] → Расшифровать аудио (на устройстве)
   → POST api.anthropic.com/v1/messages (claude-opus-5-5, JSON-схема)
   → Создать заметку + Добавить напоминания + Создать будильники
```

## Что нужно

1. iPhone 8 или новее, **iOS 18+** (нужно действие «Расшифровать аудио» / *Transcribe Audio*).
2. **API-ключ Anthropic**: [console.anthropic.com](https://console.anthropic.com) → API Keys.
   Это отдельная оплата, не подписка Claude.ai. Пополните баланс на $5–10.
3. Файл [`request-template.json`](request-template.json) из этой папки: его текст вставляется в команду.
   Читабельная версия того же: [`request-template.pretty.json`](request-template.pretty.json).

**Почему так, а не «отправить аудио Claude».** Claude API принимает текст, изображения и PDF, но не аудио.
Поэтому расшифровка делается на телефоне, а Claude получает текст.

**Стоимость.** Час разговора даёт примерно 10–20 тыс. токенов текста. При цене Opus 5.5
($4 за 1 млн входных, $20 за 1 млн выходных) это около $0.05–0.15 за запись.

## Безопасность ключа

Ключ будет храниться в команде открытым текстом. Не делитесь этой командой (кнопка «Поделиться»
отдаст её вместе с ключом). Если ключ утёк — удалите его в консоли и создайте новый.
Транскрипты уходят на сервер Anthropic; не записывайте людей без их согласия.

## Сборка команды

Создайте в «Командах» новую команду **«Claude Диктофон»**. Названия действий ниже даны по-английски
и по-русски; в поиске действий можно вводить любое из них. Набор «Переменная X» означает:
коснуться поля и выбрать волшебную переменную из результата соответствующего шага.

### Блок 1. Запись и расшифровка

1. **Record Audio / Записать аудио**
   - Качество: Normal (меньше файл, быстрее расшифровка).
   - Начало записи: **Сразу** (Immediately).
   - Окончание записи: **По касанию** (On Tap).
2. **Transcribe Audio / Расшифровать аудио** — вход: результат шага 1.
   Переименуйте результат в `Транскрипт`.
3. **If / Если** `Транскрипт` **не имеет значения** → **Show Notification / Показать уведомление**
   «Пустая запись» → **Stop This Shortcut / Остановить эту команду**. Конец «Если».

### Блок 2. Запрос к Claude

4. **Current Date / Текущая дата** → **Format Date / Форматировать дату**:
   Формат даты «Пользовательский», строка `yyyy-MM-dd'T'HH:mm:ssZZZZZ`.
   Результат назовите `Сейчас` (получится вида `2026-11-15T14:30:00+05:00`).
5. **Text / Текст**:
   ```
   Сейчас: [Сейчас]

   Транскрипт:
   [Транскрипт]
   ```
6. **Dictionary / Словарь** с двумя ключами (оба типа «Текст»):
   - `role` = `user`
   - `content` = результат шага 5.
7. **Get Text from Input / Получить текст из входных данных** — вход: словарь из шага 6.
   Получится строка JSON, где кавычки и переносы строк в транскрипте уже экранированы.
   Назовите результат `Сообщение`.
8. **Text / Текст** — вставьте **всё содержимое** `request-template.json` одной строкой.
   В конце найдите слово `MESSAGE` внутри `"messages":[MESSAGE]`, удалите его и
   на его место вставьте переменную `Сообщение`. Должно выглядеть как `"messages":[Сообщение]}`.
9. **Get Contents of URL / Получить содержимое URL**
   - URL: `https://api.anthropic.com/v1/messages`
   - Метод: **POST**
   - Заголовки:
     | Ключ | Значение |
     |---|---|
     | `x-api-key` | ваш ключ `sk-ant-...` |
     | `anthropic-version` | `2026-10-21` |
     | `anthropic-beta` | `server-side-fallback-2026-07-01` |
     | `content-type` | `application/json` |
   - Тело запроса: **Файл** (File) → результат шага 8.
   Назовите результат `Ответ`.

### Блок 3. Разбор ответа

10. **Get Dictionary Value / Получить значение из словаря** `stop_reason` из `Ответ`.
11. **If / Если** результат **не является** `end_turn`:
    **Create Note / Создать заметку** с текстом
    `Ошибка Claude [Сейчас]` + перенос строки + `Ответ` + перенос строки + `Транскрипт`
    → **Stop This Shortcut**. Конец «Если».
    Так при любой ошибке (неверный ключ, нет денег на балансе, сбой) транскрипт не потеряется.
12. **Get Dictionary Value** `content` из `Ответ` →
    **Get Item from List / Получить объект из списка**: **Последний объект** →
    **Get Dictionary Value** `text` → **Get Dictionary from Input / Получить словарь из входных данных**.
    Назовите результат `Итог`.
    (Последний, а не первый: перед текстом в ответе идёт служебный блок `thinking`.)

### Блок 4. Заметка, напоминания, будильники

13. **Format Date** для **Текущей даты**: пользовательский формат `dd.MM.yyyy HH:mm` → `Время`.
14. **Text / Текст**:
    ```
    🎙 [Время] — [Итог: title]

    [Итог: note_text]

    — Транскрипт —
    [Транскрипт]
    ```
    (Чтобы вставить `Итог: title`: выберите переменную `Итог`, коснитесь её, «Ключ» → `title`.)
15. **Create Note / Создать заметку** с текстом шага 14. Можно указать папку, например «Встречи».
16. **Get Dictionary Value** `reminders` из `Итог` → **Repeat with Each / Повторить с каждым**:
    - **Add New Reminder / Добавить новое напоминание**:
      Заголовок — `Повторяемый объект: title`; Заметки — `Повторяемый объект: notes`;
      «Напомнить» включено, дата — `Повторяемый объект: due` (у переменной выберите тип **Дата**).
    Конец повтора.
17. **Get Dictionary Value** `alarms` из `Итог` → **Repeat with Each**:
    - **Create Alarm / Создать будильник** (приложение Часы):
      Время — `Повторяемый объект: time` (тип **Дата**); Метка — `Повторяемый объект: label`.
    Конец повтора.
18. **Show Notification / Показать уведомление**: `Готово: [Итог: title]`.

## Тройной тап

Настройки → Универсальный доступ → Касание → **Касание задней панели** → **Тройное касание** →
выберите команду «Claude Диктофон».

**Остановка записи.** Надёжный способ — кнопка стоп на листе записи (или в Dynamic Island).
Повторный тройной тап может остановить запись, а может прервать всю команду: это зависит от версии iOS,
и я не могу проверить это без телефона. Проверьте коротким тестом (см. ниже). Если повторный тап
обрывает команду, останавливайте запись кнопкой.

## Проверка

1. Запустите команду из приложения и скажите 20 секунд:
   «Тест. Напомни мне завтра в десять позвонить Ивану. Поставь будильник на семь утра.
   Решили перенести релиз на пятницу.»
2. Ожидаемо: заметка с саммари, напоминание «Позвонить Ивану» на завтра 10:00, будильник 07:00.
3. Повторите с запуском тройным тапом и с остановкой повторным тройным тапом.
4. Повторите с заблокированным экраном во время записи. Если запись обрывается при блокировке,
   на время длинных встреч оставляйте экран включённым (Автоблокировка → Никогда, или поставьте на зарядку).
5. Проверьте запись на 30–60 минут: на длинных записях расшифровка может занимать несколько минут.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Заметка «Ошибка Claude» с `authentication_error` | Неверный ключ в заголовке `x-api-key`. |
| `credit balance is too low` | Пополните баланс в консоли Anthropic. |
| `invalid_request_error` про JSON | В шаге 8 переменная `Сообщение` вставлена не вместо `MESSAGE`, или текст шаблона обрезан при вставке. |
| Расшифровка пустая или на английском | Проверьте язык Siri/диктовки (Настройки → Siri). Расшифровка работает на языке устройства. |
| Напоминание без даты | В шаге 16 у переменной `due` не выбран тип «Дата». |
| Долго «думает» и падает по таймауту | Шаблон уже использует `effort: low`. Для очень длинных записей разбейте встречу на части. |

## Что внутри шаблона

- Модель `claude-opus-5-5`, `effort: low` (саммари не требует глубоких рассуждений, так быстрее).
- `output_config.format` с JSON-схемой: ответ гарантированно приходит как JSON с полями
  `title`, `note_text`, `reminders[]`, `alarms[]`, и команда может разбирать его без ошибок.
- `fallbacks: "default"` + заголовок `server-side-fallback-2026-07-01`: если фильтры безопасности
  отклонят запрос, сервер повторит его на запасной модели. Можно убрать оба, если не нужно.
- Системный промпт (поле `system`) можно править: например, попросить писать саммари короче,
  всегда по-русски или выделять задачи конкретных людей.

Если правите шаблон, держите его валидным JSON. Проверка на компьютере:

```bash
sed 's/MESSAGE/{"role":"user","content":"тест"}/' request-template.json | jq . > /dev/null && echo OK
```
