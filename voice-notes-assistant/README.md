# Голосовой ассистент: тройной тап → запись → саммари в Заметках

Команда (Shortcut) для iPhone. Тройной тап по задней крышке запускает запись. После остановки
запись расшифровывается на телефоне, текст уходит в Claude через действие **«Ask Claude»**
приложения Claude, а результат раскладывается так:

- **Заметки** — заметка с отметкой времени: кратко, ключевые моменты, решения, задачи, транскрипт;
- **Напоминания** — всё, что было сказано «напомни», «надо сделать к пятнице» и т.п.;
- **Часы** — будильники, если в записи прозвучало «поставь будильник на 7:30».

```
[тройной тап] → Записать аудио → [стоп] → Расшифровать аудио (на устройстве)
   → Ask Claude (приложение Claude, ваша подписка)
   → Создать заметку + Добавить напоминания + Создать будильники
```

**Без API-ключа и без отдельной оплаты.** Запросы идут через приложение Claude под вашим
аккаунтом и считаются в обычный лимит сообщений вашего тарифа.

## Что нужно

1. iPhone 8 или новее, **iOS 18+** (нужны действия «Расшифровать аудио» и «Ask Claude»).
2. Приложение **Claude** из App Store, вход выполнен.
3. Файл [`prompt.txt`](prompt.txt) из этой папки: его текст вставляется в команду.

**Почему расшифровка на телефоне.** Действие «Ask Claude» принимает текст. Поэтому аудио
сначала превращается в текст на устройстве.

**Что нужно учитывать.**
- Используется модель, выбранная по умолчанию в приложении Claude.
- Каждая запись расходует сообщения из лимита подписки. Длинная встреча — большое сообщение.
- Скорее всего, каждая запись появится отдельным чатом в приложении Claude.
- Транскрипты уходят на сервер Anthropic; не записывайте людей без их согласия.

## Шаг 0. Проверка, что «Ask Claude» отдаёт ответ в команду

Вся схема держится на том, что действие «Ask Claude» возвращает текст ответа следующим действиям.
В справке Anthropic это прямо не написано (сказано только, что ответы можно «обрабатывать» и
действия можно соединять в цепочку), а проверить без телефона я не могу. Проверка занимает минуту:

1. Новая команда с двумя действиями: **Ask Claude** с текстом `Ответь одним словом: тест` →
   **Show Result / Показать результат** с переменной-результатом «Ask Claude».
2. Запустите.

- Показался текст ответа — всё в порядке, собирайте команду ниже.
- Открылось приложение Claude, а в команду ничего не вернулось — эта схема не сработает.
  Напишите мне об этом, варианты описаны в разделе «Если шаг 0 не прошёл».

## Сборка команды

Действия добавляются через поле поиска внизу экрана. Названия можно вводить по-английски
(как в списке ниже), поиск их находит и в русском интерфейсе. Каждое новое действие
встаёт в самый конец команды. Если его нужно поставить внутрь блока «Если» или «Повторить»,
зажмите действие и перетащите на нужное место.

Переменные: когда курсор стоит в текстовом поле, над клавиатурой появляется полоса
с переменными. Нужную переменную выбирайте оттуда или через «Выбрать переменную».

При первом запуске iPhone несколько раз спросит разрешения (микрофон, распознавание речи,
Claude, Заметки, Напоминания). Каждый раз выбирайте «Разрешить» или «Всегда разрешать».

### Часть A. Запись и расшифровка

1. Откройте «Команды», нажмите **+**. Нажмите название вверху → «Переименовать» → `Claude Диктофон`.
2. Добавьте `Record Audio`. Нажмите стрелку **›** на действии и выставьте:
   качество — обычное; начало записи — **сразу**; окончание записи — **по касанию**.
3. Добавьте `Transcribe Audio`. В его поле сам подставится результат записи.
4. Добавьте `Set Variable`. Имя переменной: `Транскрипт`. Значение подставится само (результат шага 3).
5. Добавьте `If`. Появятся три строки: «Если», «Иначе», «Конец Если».
   В строке «Если» нажмите первое поле и выберите переменную `Транскрипт`,
   нажмите «Условие» и выберите **«не имеет значения»**.
6. Добавьте `Show Notification` с текстом `Пустая запись`. Перетащите его между «Если» и «Иначе».
7. Добавьте `Stop This Shortcut`. Перетащите его под уведомление, тоже выше «Иначе».

Все следующие действия должны стоять ниже строки «Конец Если».

### Часть B. Запрос к Claude

8. Добавьте `Format Date`. В поле даты выберите **«Текущая дата»**. Нажмите **›**:
   формат даты — **пользовательский** (Custom), в строку формата вставьте
   `yyyy-MM-dd'T'HH:mm:ssZZZZZ`.
   Скопируйте эту строку отсюда, не набирайте вручную: клавиатура iPhone заменяет прямые
   апострофы `'` на изогнутые `’`, и формат перестаёт работать.
9. Добавьте `Set Variable`, имя `Сейчас`.
10. Добавьте `Text`. Вставьте в него весь текст из `prompt.txt`. В самом конце текста:
    сотрите `[Сейчас]` и на это место вставьте переменную `Сейчас`;
    сотрите `[Транскрипт]` и на это место вставьте переменную `Транскрипт`.
11. Добавьте `Ask Claude`. В поле запроса должен стоять «Текст» (результат шага 10).
    Нажмите **›** и выключите **«Показать при запуске»**.
12. Добавьте `Set Variable`, имя `Ответ`.

### Часть C. Разбор ответа

13. Добавьте `Match Text`. В поле шаблона вставьте `(?s)\{.*\}`, в поле текста выберите `Ответ`.
14. Добавьте `Get Dictionary from Input`. Вход — «Совпадения» (подставится сам).
15. Добавьте `Set Variable`, имя `Итог`.
16. Добавьте `If`. Первое поле — переменная `Итог`, условие — **«не имеет значения»**.
17. Добавьте `Text` и перетащите между этим «Если» и его «Иначе». Текст:
    `Не разобрал ответ`, новая строка, переменная `Ответ`, новая строка, переменная `Транскрипт`.
18. Добавьте `Create Note`, перетащите под шаг 17. В поле текста — «Текст» из шага 17.
    Если у действия есть переключатель показа при запуске, выключите его.
19. Добавьте `Stop This Shortcut`, перетащите под шаг 18 (выше «Иначе»).

**Промежуточная проверка.** Нажмите ▶, скажите «Тест, напомни мне завтра в десять позвонить Ивану»,
остановите запись. Команда должна завершиться без ошибок, а в Заметках не должно появиться
заметки «Не разобрал ответ». Если появилась, откройте её: там виден ответ Claude.

### Часть D. Заметка

Все действия этой части стоят ниже второго «Конец Если».

20. Добавьте `Get Dictionary Value`. Ключ: `title`. Словарь: переменная `Итог`.
    Затем `Set Variable`, имя `Заголовок`.
21. Добавьте `Get Dictionary Value`. Ключ: `note_text`. Словарь: `Итог`.
    Затем `Set Variable`, имя `Саммари`.
22. Добавьте `Format Date`: дата — «Текущая дата», формат пользовательский `dd.MM.yyyy HH:mm`.
    Затем `Set Variable`, имя `Время`.
23. Добавьте `Text`. Соберите его из переменных и обычного текста:
    ```
    🎙 [Время] — [Заголовок]

    [Саммари]

    — Транскрипт —
    [Транскрипт]
    ```
    В квадратных скобках здесь переменные: вставляйте их из полосы над клавиатурой.
24. Добавьте `Create Note`. Текст — результат шага 23. Переключатель показа выключите.
    При желании выберите папку.

### Часть E. Напоминания

25. Добавьте `Get Dictionary Value`. Ключ: `reminders`. Словарь: `Итог`.
26. Добавьте `Repeat with Each`. Появятся строки «Повторить с каждым» и «Конец повтора».
    Действия 27–30 перетаскивайте между ними. В каждом `Get Dictionary Value` внутри повтора
    в поле словаря выбирайте переменную **«Повторяемый объект»** (сама она не подставится).
27. `Get Dictionary Value`: ключ `title`, словарь «Повторяемый объект». Затем `Set Variable`, имя `НЗаголовок`.
28. `Get Dictionary Value`: ключ `notes`, словарь «Повторяемый объект». Затем `Set Variable`, имя `НЗаметки`.
29. `Get Dictionary Value`: ключ `due`, словарь «Повторяемый объект». Затем `Get Dates from Input`.
    Затем `Set Variable`, имя `НСрок`.
30. `Add New Reminder`. Название — `НЗаголовок`. Нажмите **›**: оповещение — **в заданное время**,
    время — `НСрок`; заметки — `НЗаметки`.

### Часть F. Будильники и финал

Действие 31 стоит ниже «Конец повтора» из части E.

31. Добавьте `Get Dictionary Value`. Ключ: `alarms`. Словарь: `Итог`.
32. Добавьте `Repeat with Each`. Действия 33–35 перетащите внутрь.
33. `Get Dictionary Value`: ключ `time`, словарь «Повторяемый объект». Затем `Set Variable`, имя `БВремя`.
34. `Get Dictionary Value`: ключ `label`, словарь «Повторяемый объект». Затем `Set Variable`, имя `БМетка`.
35. `Create Alarm`. Время — `БВремя`, название — `БМетка`.
36. Ниже последнего «Конец повтора» добавьте `Show Notification` с текстом `Готово: ` и переменной `Заголовок`.

Нажмите «Готово» вверху, чтобы сохранить команду.

## Тройной тап

Настройки → Универсальный доступ → Касание → **Касание задней панели** → **Тройное касание** →
выберите команду «Claude Диктофон».

**Остановка записи.** Надёжный способ — кнопка стоп на листе записи (или в Dynamic Island).
Повторный тройной тап может остановить запись, а может прервать всю команду: это зависит от версии iOS,
и я не могу проверить это без телефона. Проверьте коротким тестом (см. ниже). Если повторный тап
обрывает команду, останавливайте запись кнопкой.

## Проверка

1. Запустите команду из приложения и скажите 20 секунд:
   «Тест. Напомни мне завтра в десять позвонить Ивану. Поставь будильник на семь утра.
   Решили перенести релиз на пятницу.»
2. Ожидаемо: заметка с саммари, напоминание «Позвонить Ивану» на завтра 10:00, будильник 07:00.
3. Повторите с запуском тройным тапом и с остановкой повторным тройным тапом.
4. Повторите с заблокированным экраном во время записи. Если запись обрывается при блокировке
   или «Ask Claude» требует разблокировки, на время длинных встреч оставляйте экран включённым.
5. Проверьте запись на 30–60 минут: расшифровка может занимать несколько минут, а очень длинный
   текст может не пройти в одно сообщение.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Заметка «Не разобрал ответ» | Claude ответил не JSON-ом или ответ пустой. Посмотрите сырой ответ в заметке. Если там сообщение о лимите — лимит подписки исчерпан, подождите сброса. |
| «Ask Claude» открывает приложение и команда останавливается | См. «Если шаг 0 не прошёл». |
| Расшифровка пустая или на английском | Проверьте язык Siri/диктовки (Настройки → Siri). Расшифровка работает на языке устройства. |
| Напоминание без даты | Проверьте шаг 29: после `due` должно стоять действие `Get Dates from Input`, а в шаге 30 оповещение включено «в заданное время». |
| Саммари слабое | В приложении Claude выберите по умолчанию более сильную модель: действие использует её. |

## Если шаг 0 не прошёл

Если «Ask Claude» не возвращает ответ в команду, без ключа остаются два пути:

1. **Полуавтомат.** Команда записывает, расшифровывает и открывает Claude с готовым запросом.
   Саммари читается в чате, а заметку и напоминания команда создать не сможет.
2. **Действие Apple «Use Model»** (iOS 26+, iPhone с Apple Intelligence). Бесплатно и без ключа,
   ответ возвращается в команду, но это модель Apple или ChatGPT, а не Claude, и Apple Intelligence
   может быть недоступен при русском языке системы.

## Настройка под себя

Правьте `prompt.txt` (и текст в шаге 10): можно попросить саммари короче, всегда по-русски,
выделять задачи конкретных людей. Не меняйте названия полей JSON (`title`, `note_text`,
`reminders`, `alarms`, `due`, `time`, `label`, `notes`): на них опирается команда.
