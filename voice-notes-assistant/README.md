# Голосовой ассистент: тройной тап → запись → саммари в Заметках

Команда (Shortcut) для iPhone. Тройной тап по задней крышке запускает запись. После остановки
запись расшифровывается на телефоне, текст уходит в Claude через действие **«Ask Claude»**
приложения Claude, а результат раскладывается так:

- **Заметки** — заметка с отметкой времени: кратко, ключевые моменты, решения, задачи, транскрипт;
- **Напоминания** — всё, что было сказано «напомни», «надо сделать к пятнице» и т.п.;
- **Часы** — будильники, если в записи прозвучало «поставь будильник на 7:30».

```
[тройной тап] → Записать аудио → [стоп] → Расшифровать аудио (на устройстве)
   → Ask Claude (приложение Claude, ваша подписка)
   → Создать заметку + Добавить напоминания + Создать будильники
```

**Без API-ключа и без отдельной оплаты.** Запросы идут через приложение Claude под вашим
аккаунтом и считаются в обычный лимит сообщений вашего тарифа.

## Что нужно

1. iPhone 8 или новее, **iOS 18+** (нужны действия «Расшифровать аудио» и «Ask Claude»).
2. Приложение **Claude** из App Store, вход выполнен.
3. Файл [`prompt.txt`](prompt.txt) из этой папки: его текст вставляется в команду.

**Почему расшифровка на телефоне.** Действие «Ask Claude» принимает текст. Поэтому аудио
сначала превращается в текст на устройстве.

**Что нужно учитывать.**
- Используется модель, выбранная по умолчанию в приложении Claude.
- Каждая запись расходует сообщения из лимита подписки. Длинная встреча — большое сообщение.
- Скорее всего, каждая запись появится отдельным чатом в приложении Claude.
- Транскрипты уходят на сервер Anthropic; не записывайте людей без их согласия.

## Шаг 0. Проверка, что «Ask Claude» отдаёт ответ в команду

Вся схема держится на том, что действие «Ask Claude» возвращает текст ответа следующим действиям.
В справке Anthropic это прямо не написано (сказано только, что ответы можно «обрабатывать» и
действия можно соединять в цепочку), а проверить без телефона я не могу. Проверка занимает минуту:

1. Новая команда с двумя действиями: **Ask Claude** с текстом `Ответь одним словом: тест` →
   **Show Result / Показать результат** с переменной-результатом «Ask Claude».
2. Запустите.

- Показался текст ответа — всё в порядке, собирайте команду ниже.
- Открылось приложение Claude, а в команду ничего не вернулось — эта схема не сработает.
  Напишите мне об этом, варианты описаны в разделе «Если шаг 0 не прошёл».

## Сборка команды

Создайте в «Командах» новую команду **«Claude Диктофон»**. Названия действий даны по-английски
и по-русски; в поиске действий можно вводить любое из них. «Переменная X» означает: коснуться
поля и выбрать волшебную переменную из результата соответствующего шага.

### Блок 1. Запись и расшифровка

1. **Record Audio / Записать аудио**
   - Качество: Normal (меньше файл, быстрее расшифровка).
   - Начало записи: **Сразу** (Immediately).
   - Окончание записи: **По касанию** (On Tap).
2. **Transcribe Audio / Расшифровать аудио** — вход: результат шага 1.
   Переименуйте результат в `Транскрипт`.
3. **If / Если** `Транскрипт` **не имеет значения** → **Show Notification / Показать уведомление**
   «Пустая запись» → **Stop This Shortcut / Остановить эту команду**. Конец «Если».

### Блок 2. Запрос к Claude

4. **Current Date / Текущая дата** → **Format Date / Форматировать дату**:
   Формат даты «Пользовательский», строка `yyyy-MM-dd'T'HH:mm:ssZZZZZ`.
   Результат назовите `Сейчас` (получится вида `2026-11-15T14:30:00+05:00`).
5. **Text / Текст** — вставьте всё содержимое `prompt.txt`. В конце текста замените
   `[Сейчас]` на переменную `Сейчас`, а `[Транскрипт]` на переменную `Транскрипт`.
6. **Ask Claude** (приложение Claude) — в поле запроса поставьте результат шага 5.
   Назовите результат `Ответ`.

### Блок 3. Разбор ответа

7. **Match Text / Найти совпадения в тексте** — текст: `Ответ`, шаблон: `(?s)\{.*\}`.
   Это вырезает JSON, даже если Claude добавил лишний текст или обёртку ``` вокруг.
8. **Get Dictionary from Input / Получить словарь из входных данных** — вход: результат шага 7.
   Назовите результат `Итог`.
9. **If / Если** `Итог` **не имеет значения**:
   **Create Note / Создать заметку** с текстом
   `Не разобрал ответ [Сейчас]` + перенос строки + `Ответ` + перенос строки + `Транскрипт`
   → **Stop This Shortcut**. Конец «Если».
   Так при любом сбое транскрипт и сырой ответ не потеряются.

### Блок 4. Заметка, напоминания, будильники

10. **Format Date** для **Текущей даты**: пользовательский формат `dd.MM.yyyy HH:mm` → `Время`.
11. **Text / Текст**:
    ```
    🎙 [Время] — [Итог: title]

    [Итог: note_text]

    — Транскрипт —
    [Транскрипт]
    ```
    (Чтобы вставить `Итог: title`: выберите переменную `Итог`, коснитесь её, «Ключ» → `title`.)
12. **Create Note / Создать заметку** с текстом шага 11. Можно указать папку, например «Встречи».
13. **Get Dictionary Value / Получить значение из словаря** `reminders` из `Итог` →
    **Repeat with Each / Повторить с каждым**:
    - **Add New Reminder / Добавить новое напоминание**:
      Заголовок — `Повторяемый объект: title`; Заметки — `Повторяемый объект: notes`;
      «Напомнить» включено, дата — `Повторяемый объект: due` (у переменной выберите тип **Дата**).
    Конец повтора.
14. **Get Dictionary Value** `alarms` из `Итог` → **Repeat with Each**:
    - **Create Alarm / Создать будильник** (приложение Часы):
      Время — `Повторяемый объект: time` (тип **Дата**); Метка — `Повторяемый объект: label`.
    Конец повтора.
15. **Show Notification / Показать уведомление**: `Готово: [Итог: title]`.

## Тройной тап

Настройки → Универсальный доступ → Касание → **Касание задней панели** → **Тройное касание** →
выберите команду «Claude Диктофон».

**Остановка записи.** Надёжный способ — кнопка стоп на листе записи (или в Dynamic Island).
Повторный тройной тап может остановить запись, а может прервать всю команду: это зависит от версии iOS,
и я не могу проверить это без телефона. Проверьте коротким тестом (см. ниже). Если повторный тап
обрывает команду, останавливайте запись кнопкой.

## Проверка

1. Запустите команду из приложения и скажите 20 секунд:
   «Тест. Напомни мне завтра в десять позвонить Ивану. Поставь будильник на семь утра.
   Решили перенести релиз на пятницу.»
2. Ожидаемо: заметка с саммари, напоминание «Позвонить Ивану» на завтра 10:00, будильник 07:00.
3. Повторите с запуском тройным тапом и с остановкой повторным тройным тапом.
4. Повторите с заблокированным экраном во время записи. Если запись обрывается при блокировке
   или «Ask Claude» требует разблокировки, на время длинных встреч оставляйте экран включённым.
5. Проверьте запись на 30–60 минут: расшифровка может занимать несколько минут, а очень длинный
   текст может не пройти в одно сообщение.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Заметка «Не разобрал ответ» | Claude ответил не JSON-ом или ответ пустой. Посмотрите сырой ответ в заметке. Если там сообщение о лимите — лимит подписки исчерпан, подождите сброса. |
| «Ask Claude» открывает приложение и команда останавливается | См. «Если шаг 0 не прошёл». |
| Расшифровка пустая или на английском | Проверьте язык Siri/диктовки (Настройки → Siri). Расшифровка работает на языке устройства. |
| Напоминание без даты | В шаге 13 у переменной `due` не выбран тип «Дата». |
| Саммари слабое | В приложении Claude выберите по умолчанию более сильную модель: действие использует её. |

## Если шаг 0 не прошёл

Если «Ask Claude» не возвращает ответ в команду, без ключа остаются два пути:

1. **Полуавтомат.** Команда записывает, расшифровывает и открывает Claude с готовым запросом.
   Саммари читается в чате, а заметку и напоминания команда создать не сможет.
2. **Действие Apple «Use Model»** (iOS 26+, iPhone с Apple Intelligence). Бесплатно и без ключа,
   ответ возвращается в команду, но это модель Apple или ChatGPT, а не Claude, и Apple Intelligence
   может быть недоступен при русском языке системы.

## Настройка под себя

Правьте `prompt.txt` (и текст в шаге 5): можно попросить саммари короче, всегда по-русски,
выделять задачи конкретных людей. Не меняйте названия полей JSON (`title`, `note_text`,
`reminders`, `alarms`, `due`, `time`, `label`, `notes`): на них опирается команда.
